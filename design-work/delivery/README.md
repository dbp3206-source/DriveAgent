# Deliverable

Đầu ra chỉnh sửa được là chính repository này:

- `backend/`: FastAPI, Google OAuth2, Tool Registry, RAG, Memory, LangGraph.
- `frontend/`: React + TypeScript + Fluent UI.
- `scripts/`: setup, chạy local và xác minh.
- `docs/`: hướng dẫn sử dụng và giải thích kiến trúc.

Ảnh preview cuối nằm tại `../qa/screenshots/`; Lighthouse report nằm tại
`../qa/validation/`.
